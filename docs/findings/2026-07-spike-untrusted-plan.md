## 结论

`rustix` 的 `openat` + `O_NOFOLLOW` 逐段遍历在 macOS 上按预期工作。三个攻击用例全部被拒绝：

| 攻击 | 拒绝机制 | 结果 |
|---|---|---|
| 路径不存在 | `statat` 失败 | 通过 |
| 末段换成 symlink | inode 不匹配 | 通过 |
| 中间段换成 symlink | `openat` NOFOLLOW 在中间段拒绝 | 通过 |

攻击三的错误信息为「路径段 … 打开失败（可能是 symlink）」，符合设计——不是在末段 inode 比对时才拦下，说明逐段遍历生效。
