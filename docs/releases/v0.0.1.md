# v0.0.1 — Phase 4c v1 首版

**日期**：2026-07-29  
**平台**：macOS 12+（Apple Silicon / Intel）  
**签名**：ad-hoc（无 Developer ID；Gatekeeper 可能提示，见下方安装说明）

## 亮点

- **`vole clean`** — 150 条 macOS 清理规则（`--plan` / `--apply`、`--json-stream`）
- **`vole status` / `analyze` / `history`** — 监控、目录分析、操作历史
- **Mole 衍生** — 规则知识来自 Mole v1.48.1；未覆盖类别在 plan 中提示继续用 Mole
- **GPL-3.0-only**

## 安装

### 预编译包（推荐）

```bash
# Apple Silicon
curl -LO https://github.com/wukongnotnull/vole/releases/download/v0.0.1/vole-0.0.1-aarch64-apple-darwin.tar.gz
tar xzf vole-0.0.1-aarch64-apple-darwin.tar.gz
install -m 755 vole-0.0.1-aarch64-apple-darwin/bin/vole ~/.local/bin/vole
# 规则目录（与二进制同包）
mkdir -p ~/.local/share/vole
cp -R vole-0.0.1-aarch64-apple-darwin/share/vole/rules ~/.local/share/vole/
export VOLE_RULES_DIR="$HOME/.local/share/vole/rules"  # 或写入 shell rc
```

Intel 机器将 `aarch64` 换为 `x86_64-apple-darwin`。

首次运行若被 Gatekeeper 拦截：`xattr -cr ~/.local/bin/vole` 或在系统设置中允许。

### 源码构建

```bash
git clone https://github.com/wukongnotnull/vole.git
cd vole
./install.sh   # 安装到 $PREFIX/bin（默认 ~/.local/bin）并复制 rules
```

### Homebrew（草稿）

见仓库 `HomebrewFormula/vole.rb` — 有 Developer ID 后填 release `url`/`sha256` 或 `brew install --build-from-source`。
