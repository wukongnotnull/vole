- **`vole clean`** — **390** 条 macOS 清理规则（v0.0.4 为 350）

## 安装

```bash
curl -LO https://github.com/wukongnotnull/vole/releases/download/v0.0.5/vole-0.0.5-aarch64-apple-darwin.tar.gz
tar xzf vole-0.0.5-aarch64-apple-darwin.tar.gz
install -m 755 vole-0.0.5-aarch64-apple-darwin/bin/vole ~/.local/bin/vole
mkdir -p ~/.local/share/vole && cp -R vole-0.0.5-aarch64-apple-darwin/share/vole/rules ~/.local/share/vole/
export VOLE_RULES_DIR="$HOME/.local/share/vole/rules"
```
