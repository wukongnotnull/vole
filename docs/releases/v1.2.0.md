## 安装

暂未进 Homebrew Core（知名度未达标）。推荐自建 tap（无需 `VOLE_RULES_DIR`）：

```bash
brew tap wukongnotnull/vole https://github.com/wukongnotnull/vole
brew install vole
# 已装则：
brew upgrade vole
```

或预编译包（保持 `bin` + `share/vole/rules` 相对布局）：

```bash
curl -LO https://github.com/wukongnotnull/vole/releases/download/v1.2.0/vole-1.2.0-aarch64-apple-darwin.tar.gz
```

完整说明见仓库 [README](https://github.com/wukongnotnull/vole#快速开始)。
