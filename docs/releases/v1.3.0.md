# v1.3.0 — 用户域 orphaned app data（B4）

**日期**：2026-08-05  
**平台**：macOS 12+（Apple Silicon / Intel）  
**签名**：Developer ID Application（tag 触发 Release 流水线）  
**公证**：Apple Notary Service

## 亮点

- **`vole clean` 纳入用户域 orphaned app data**：`~/Library/{Caches,Logs,Saved Application State}` 下无对应已装 app、且 mtime ≥ 30 天的 `com.*`/`org.*`/`net.*`/`io.*` 条目可进入 plan
- 安全闸口对齐 Mole 并加强：敏感族、保护层、安装/运行/LaunchAgents 证据、Spotlight 可用性探测、mdfind fail-closed、apply 完整重判
- 规则 id：`orphaned-app-data`（加载序最后，同路径去重时具名规则优先）
- 环境变量：`MOLE_ORPHAN_AGE_DAYS`（默认 30，下限 7）
- 规则条数：**512**

## 非目标（本版）

- Claude VM orphan（B4.1）
- system services / PrivilegedHelperTools orphan（需 sudo）
- Containers / Group Containers / LaunchAgents 删除
- `purge` / 真 sudo / SwiftUI
