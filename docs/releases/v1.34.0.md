## 新增

- **`vole uninstall` Login Items 联动（W2a②）**
  - plan：侧车 `uninstall:login-item:name:…`（按显示名）与 `uninstall:login-helper:{bundle_id}`（`Contents/Library/LoginItems`）
  - sibling → 跳过 helper bootout；display name 与 survivor 冲突 → 跳过按名删 Login Item
  - apply：osascript System Events / `launchctl bootout gui/$uid/$id`（`LoginItemDeps` 可注入）；TCC → NeedsPrivilege skip，不阻塞同 plan 其它条目；侧车 **不** `mole_delete`
  - 永不 bootout `com.apple.*`
