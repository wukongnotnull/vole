# v1.38.0

## 新增

- `vole optimize`：W2b③ 三项进入主路径
  - `network_stack_optimize`：VPN 或网络健康 → noop；否则 `sudo -n route -n flush` + `sudo -n arp -a -d`
  - `disk_permissions_repair`：无需修复 → noop；否则 `sudo -n diskutil resetUserPermissions / <uid>`
  - `periodic_maintenance`：`periodic` 缺失或 daily 日志未过期 → noop；否则 `sudo -n periodic daily weekly monthly`
  - 复用 `PrivilegeBackend` + TTY `sudo -v`；无凭证 → NeedsPrivilege + 响亮提示
