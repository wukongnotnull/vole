# v1.4.0 — Claude Desktop workspace VM orphan（B4.1）

**日期**：2026-08-05  
**平台**：macOS 12+（Apple Silicon / Intel）  
**签名**：Developer ID Application（tag 触发 Release 流水线）  
**公证**：Apple Notary Service

## 亮点

- Claude Desktop workspace VM orphan：`$HOME/Library/Application Support/Claude` 下 depth≤3 的 `*.bundle`（自举 walk，对齐 Mole `find -maxdepth 3`）
- 判定对齐 Mole `is_claude_vm_bundle_orphaned`：Claude 进程 / `com.anthropic.claudefordesktop` 安装证据 / 年龄 / Spotlight+mdfind fail-closed；apply 重判分流
- 环境变量：`MOLE_CLAUDE_VM_ORPHAN_AGE_DAYS`（默认 **7**；非法或空 → 7）
- 仍挂同一规则：`orphaned-app-data` / handler `orphaned_app_data`
- 与 `ai-agents` 的 Claude Desktop bundled keep-N **无关**

## 非目标（本版）

- system services / PrivilegedHelperTools orphan（需 sudo）
- Containers / Group Containers / LaunchAgents 删除
- 泛扫其它 Application Support
- `purge` / 真 sudo / SwiftUI
