# v1.46.0

## 新增

- `vole optimize`：`disk_verify` 进入主路径（闸控轨 G5 · **推翻默认**）
  - **风险**：`diskutil verifyVolume` 在 APFS 异常时可能触发不可中断内核 I/O、整机卡住；故默认不执行
  - 须 `VOLE_ENABLE_DISK_VERIFY=1` 才出 plan 候选并在 apply 时扫盘（对齐 Mole `MOLE_ENABLE_DISK_VERIFY`）
  - apply：超时（默认 30s，`VOLE_TIMEOUT_DISK_VERIFY_SEC`）跑 `diskutil verifyVolume /`；超时 → Failed
  - **禁止** `repairVolume` / `repairDisk`；issues 仅诊断，由用户自行决定是否手动 repair
  - `VOLE_TEST_NO_AUTH=1` → 永不真跑 diskutil（空 plan / apply Skipped）
