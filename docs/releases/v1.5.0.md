# v1.5.0 — system services orphan（可读子集）

**日期**：2026-08-05  
**平台**：macOS 12+（Apple Silicon / Intel）  
**签名**：Developer ID Application（tag 触发 Release 流水线）  
**公证**：Apple Notary Service

## 亮点

- **`orphaned-system-services`**：扫描 `/Library/LaunchDaemons`、`/Library/LaunchAgents`、`/Library/PrivilegedHelperTools` 的**当前用户可读子集**，发现可能残留的 LaunchDaemon/Agent/PrivilegedHelper
- **无 sudo**：不调用 `sudo`；存在性探测 fail-closed（祖先不可进入 / 权限错误 ≠ 缺失）；含 package-managed 排除与 Mole #1082 PHT 父 app 判定
- **发现优先，删除不承诺**：系统路径候选进入 plan 后，apply **硬跳过**（`NeedsPrivilege`），不执行删除。完整删除请用 Mole 或未来提权能力
- **`vole clean --apply`**：补齐与 uninstall/optimize 同形的权限响亮提示（1.4.2 未覆盖 clean）
- 规则数 **513**；零协议 `schema_version` bump

## 非目标（本版）

- 真 sudo / 特权助手删除
- Containers / Group Containers stubs
- `~/Library/LaunchAgents` 作为本规则删除目标
