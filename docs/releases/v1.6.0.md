# v1.6.0 — container stubs orphan（CleanMyMac allowlist）

**日期**：2026-08-05  
**平台**：macOS 12+（Apple Silicon / Intel）  
**签名**：Developer ID Application（tag 触发 Release 流水线）  
**公证**：Apple Notary Service

## 亮点

- **`orphaned-container-stubs`**：清理卸载后残留在 `~/Library/Containers` 的沙盒容器 stub（对齐 Mole `clean_orphaned_container_stubs`）
- **硬编码 allowlist**：仅 `com.macpaw.CleanMyMac*` 与 `*.com.macpaw.CleanMyMac*`（含 TeamID 前缀变体）；扩表须单独设计评审
- **stub 双重闸口**：非 symlink 目录且唯一子项为 `.com.apple.containermanagerd.metadata.plist`（无 `Data/`、无任何用户数据）才入选；app 存在探测（canonical / `~/Applications` / Setapp / mdfind fail-closed）命中即跳过
- **apply 专用 carve-out**：重验 stub 形状 + 目录身份（TOCTOU）后 `unlink` metadata + `rmdir`；**不进废纸篓**、**不递归**、`--permanent` 不适用；plan→apply 之间长出任何内容都会原样保留
- **保护层不放宽**：`com.macpaw.*` 仍在 `data_protected_bundles`；其它 Containers 路径的普通删除仍被全局保护拒绝（豁免面仅限本规则 + 单层形状校验）
- `~/Library/Containers` 不可读 → 响亮降级（`TccDenied` + FDA 指引），不静默空结果
- 规则数 **514**；零协议 `schema_version` bump

## 非目标（本版）

- Group Containers / 泛容器清理
- 扩展 allowlist 超 Mole 1.48.1 钉版列表
- stub 进废纸篓 / `rm -r`
- 真 sudo
