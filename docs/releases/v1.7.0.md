# v1.7.0 — Group Containers logs/caches（Mole 同形，零保护层改动）

**日期**：2026-08-06  
**平台**：macOS 12+（Apple Silicon / Intel）  
**签名**：Developer ID Application（tag 触发 Release 流水线）  
**公证**：Apple Notary Service

## 亮点

- **`group-container-caches`**：清理 `$HOME/Library/Group Containers` 内 Logs，以及非 `data_protected` 容器的 Caches/tmp **叶节点**（对齐 Mole `clean_group_container_caches`）
- **零保护层改动**：`group.*` 前缀容器今天已可通过 `should_protect_path`；本期不放宽步骤 3/6/7。受保护 id（如 `com.macpaw.*`）的 Logs / 叶子文件名命中 bundle guard 的条目仍会在 plan 层 skip
- **TeamID 归一化比 Mole 更严**：原 id / 去 `group.` / 去前导 10 位 TeamID / 两者都去，任一命中 `should_protect_data` 即只提 Logs
- **跳过**：Apple 前缀容器、Safari Web Extension（Containers 探测 fail-closed，含目录不可读）
- **规模上限**：单候选子树 >200 或整规则 >2000 → 整树不提候选 + truncated 响亮提示（禁止提目录本身）
- **apply**：普通 `mole_delete_verified`（默认废纸篓，`--permanent` 有效）；**无** carve-out / protect 豁免
- FDA：根不可读 → `TccDenied` + 完全磁盘访问指引
- 规则数 **515**；零协议 `schema_version` bump

## 非目标（本版）

- 保护层放行受保护容器 Logs / bundle 命名日志文件（另开 1.8.0 design）
- 整 Group Container orphan / Application Scripts
- 真 sudo
