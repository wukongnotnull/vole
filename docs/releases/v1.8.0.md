# v1.8.0 — Handoff pasteboard cache（mtime>60min）

**日期**：2026-08-06  
**平台**：macOS 12+（Apple Silicon / Intel）  
**签名**：Developer ID Application（tag 触发 Release 流水线）  
**公证**：Apple Notary Service

## 亮点

- **`handoff-pasteboard-cache`**：清理 Handoff / Universal Clipboard 暂存目录 `~/Library/Group Containers/group.com.apple.coreservices.useractivityd/shared-pasteboard` 下 **mtime > 60 分钟** 的叶节点（对齐 Mole `clean_handoff_pasteboard_cache` / #1178）
- **零保护层改动、零 skip_protection**：探针确认该路径今天即可通过 `should_protect_path`；apply 仅做根形状 + mtime 政策重验，仍走普通 `mole_delete_verified`（废纸篓 / `--permanent`）
- 根不可读 → FDA 响亮提示；整规则 >2000 叶截断 notice
- 规则数 **516**；零协议 `schema_version` bump

## 非目标（本版）

- 其它 Apple Group Containers / 受保护组容器 Logs 放行（另开 design）
- 改保护层「剥 group.」归一化
- Application Scripts / 真 sudo
