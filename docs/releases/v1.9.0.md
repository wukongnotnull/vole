**日期**：2026-08-06  
**平台**：macOS 12+（Apple Silicon / Intel）  
**签名**：Developer ID Application（tag 触发 Release 流水线）  
**公证**：Apple Notary Service

## 亮点

- **补齐 1.7.0 覆盖缺口**：在 `should_protect_path` 对 Group Containers 下可再生 **Logs** 叶做形状豁免
  - `data_protected` 且无 `group.` 前缀的容器（如 `com.macpaw.CleanMyMac`）Logs 叶可入 plan / apply
  - Logs 叶文件名命中 bundle guard（如 `com.docker.helper.log`）可入 plan / apply
- **纵深**：同容器 Caches / tmp 对 protected 仍拦（handler 不提 + 保护层双保险）
- Notes / OrbStack / 非 Group Containers 行为零退化
- 规则数 **516**；零协议 `schema_version` bump；无新规则 / 无 apply 旁路

## 非目标（本版）

- 对 protected 容器放行 Caches / tmp
- 真 sudo / Rosetta `/Library` / claude pending-uploads
- Application Scripts / 整 Group Container orphan
