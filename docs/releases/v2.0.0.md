# v2.0.0

产品 **v2** 包线首发（MAJOR）：CLI 做全续篇首个功能里程碑。

## 新增

- `vole purge`：陈旧项目构建物清理（高对齐 Mole `purge` 主路径）
  - `--plan` / `--dry-run` / `-n` → 候选集；`--apply PLAN` → TTL + TOCTOU + 删除漏斗
  - JSON / `--json-stream` / `--plan-out`；默认废纸篓（`--permanent`）
  - Targets 钉 `third_party/mole-1.48.1` `MOLE_PURGE_TARGETS`；年龄默认 7 天
  - `rule_id` 前缀 `purge:`；覆盖说明记录长尾（TTY 多选、完整 activity 分类等）
- 命令名兼容别名（§3.3）：`optimise`、`analyse`、`completion`
- 交互菜单增加 `purge --plan`

## 承接
