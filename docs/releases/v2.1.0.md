# v2.1.0

产品 v2 续篇 **M6**：`clean` 内只读 hints 模块。

## 新增

- `vole clean --plan` 结束后追加非破坏提示（Mole `lib/clean/hints.sh` 主路径子集）
  - **项目构建物快捷探针**：读 `~/.config/vole/purge_paths`（或默认搜索根），浅扫 quick-hint targets（排除 `bin`/`vendor`），引导 `vole purge`
  - **System Data 大路径线索**：DerivedData / Archives / backups / Simulator / Docker / Mail / OrbStack；≥2GiB 才展示
  - 墙钟预算默认 15s（`VOLE_TIMEOUT_HINT_SCAN_SEC`）；超时跳过提示，不阻塞 clean
- plan JSON / `--plan-out` 可选 `hints` 数组（`kind` / `summary` / `detail`）；不 bump `schema_version`
- **禁止**顶层 `vole hints` 子命令

## 承接

- 含 **2.0.0** `purge` 与命令别名
