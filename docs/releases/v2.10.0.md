# v2.10.0

T6：`clean` / `optimize` TTY 确认双轨（扫 plan → `Proceed? [y/N]` → 既有 apply）。

## 新增 / 相对 2.9.0

- **`vole clean`（TTY 裸调用）**：扫 plan → 人类摘要 → `Proceed with clean? [y/N]`（默认 N）→ 内存 plan 走 `apply_proto_plan`
- **`vole optimize`（TTY 裸调用）**：同形 → `Proceed with optimize? [y/N]` → `apply_optimize_plan`
- **首页衔接**：T5 exec 裸子命令后，Enter Clean/Optimize 即真确认流
- **`--permanent`**：可在交互确认路径单独使用（与 uninstall 一致）

## 不变

- `--plan` / `-n` / `--dry-run` / `--apply` / `--json*` / `--plan-out` / 非 TTY：行为不变（仍只 plan 或显式 apply）
- `clean` whitelist 系 flag：仍走既有 whitelist 路径，不进本确认轨
- 删除只走既有 apply 漏斗；**不 bump** `schema_version`

## 有意不做（T7–T8）

- T8：status 动画 cat / prefs；`optimize --whitelist`；对照表收口
- clean 分页多选单条
