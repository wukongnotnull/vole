# v2.11.0

T7：`analyze` 进阶键（Space 多选、⌫/Delete、O Open、P Preview、`/` Filter、T Top）。

## 新增 / 相对 2.10.0

- **Space**：目录 / Top 列表多选（overview / 扫描中禁用）
- **⌫ / Delete**：确认后删除；固定走 `mole_delete` + `DeleteMode::Trash` + 保护校验（**禁止**平行 `rm`）
- **O Open**：打开选中项（多选上限 20）
- **P Preview**：Quick Look 预览单文件
- **`/` Filter**：名称过滤（改查询清空多选）
- **T Top**：切换 Large files 全屏列表
- **诚实 footer**：只声明已接线键（不虚标 `F File` / `R Refresh`）

## 不变

- `analyze --json` / 非 TTY 路径
- 删除漏斗语义（保护 + 废纸篓）
- **不 bump** `schema_version`

## 有意不做（T8 / 后续）

- `F` Finder reveal、`R` Refresh
- status 动画 cat / prefs
- `optimize --whitelist`
- README 对照表全面收口（可随 T8）
