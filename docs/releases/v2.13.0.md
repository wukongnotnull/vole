# v2.13.0

T9：`analyze` `F` Finder reveal + `R` Refresh。

## 新增 / 相对 2.12.0

- **`F` / `f`**：Finder reveal（`/usr/bin/open -R`）；多选上限 20（与 Open 同）
- **`R` / `r`**：强制重扫当前路径（清空多选；stack 不变；vole 无 mole 磁盘 cache）
- **诚实 footer**：声明 `F File` / `R Refresh`（仍不虚标 `S Live` / 导航别名）

## 不变

- `analyze --json` / 非 TTY 路径
- 删除漏斗语义（保护 + 废纸篓）
- **不 bump** `schema_version`

## 有意不做

- `←`/`→`/`h`/`b` 导航别名
- 扫描中 `S` live sort
- mole 磁盘 / overview cache 复刻
