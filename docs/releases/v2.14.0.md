# v2.14.0

## 新增 / 相对 2.13.0

- **导航别名**：`←` / `h` / `b` 返回；`→` / `l` 进入目录（过滤输入态除外）
- **诚实 footer**：Directory `↑↓←→`（根 `↑↓→`）；Top `↑↓←`
- **`S` / `s` live sort**（仅扫描中、非 overview / Top）：`continuous` ↔ `freeze-on-move`；状态行提示；默认 freeze；`VOLE_ANALYZE_LIVE_SORT`（兼容 `MOLE_ANALYZE_LIVE_SORT`）
- **渐进扫描**：根子项完成即刷新列表（支撑 live sort）；**无** mole 磁盘 cache

## 不变

- footer **不**声明 `S Live`（对齐 mole；仅状态行）
