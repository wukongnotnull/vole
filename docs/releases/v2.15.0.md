# v2.15.0

TUI design system + status/home/analyze 视觉收口：田鼠吉祥物、dark/light 主题轨、布局与 footer 统一。

## 新增 / 相对 2.14.0

- **Status 吉祥物**：行走猫改为正面田鼠（logo 形）；`K Vole` 切换显示
- **`B Back`**：Status 恢复终端后回到裸 `vole` 首页
- **Design system**：`tui/design`（tokens / Theme dark·light / 组件 footer·标题 / inset 布局）；`VOLE_THEME` + `COLORFGBG` 解析
- **布局标准**：外沿水平 pad、顶 pad、卡片内容高度、footer 紧贴卡片、键位提示间距与强调
- **Home / Analyze / Menu**：与 status chrome 对齐（inset、footer 样式）
- **Light 对比度**：更深 ink / bar track；进度条 fill 与 track 分色；header 健康文案可读
- **文档**：README 多语言页 + 首页截图

## 不变

- 删除漏斗语义（保护 + 废纸篓）
- `analyze` / `status` JSON 与非 TTY 行为
- **不 bump** `schema_version`

## 有意不做

- 更强自动 light 探测（如 OSC / `termbg`）
