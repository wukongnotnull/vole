# v2.17.0

Interactive `vole clean` plan is grouped by exclusive app vs shared system buckets, with a highlighted size summary.

## Added / changed since 2.16.0

- **Clean plan (human)**: exclusive app folders stay under the app; shared type directories merge into 系统缓存 / 系统日志 / 临时文件
- **Paths**: stop at the type directory (`C`/`T`/`X`, `/var/log`, `/tmp`, …); print absolute `/…` paths so the terminal can open them
- **Summary**: footer leads with reclaimable total (bold gold on a TTY), plus groups / types / items
- **Scan spinner**: `Scanning caches, logs, leftovers...`
- **Paths**: config and logs write under vole’s own directories
- **Docs**: README install options include an AI prompt; numbered Homebrew then download

## Unchanged

- Delete funnel semantics (protection + Trash)
- Plan / apply JSON shapes and `schema_version`
- **No** `schema_version` bump
