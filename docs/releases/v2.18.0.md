# v2.18.0

New `vole worktree` command lists leftover Git worktrees and moves selected checkouts to Trash after you confirm.

## Added / changed since 2.17.0

- **Command**: `vole worktree` inventories official Git worktrees and agent containers (Cursor / Codex / Claude)
- **Flow**: heuristic sort, blockers shown, TTY multi-select starts with nothing preselected, then Trash + `git worktree prune`
- **Safety**: never claims a worktree is safe to delete; primary checkout and the cwd worktree are hard-excluded
- **Home**: sixth menu item Worktree (digit 6); digits 1–5 unchanged
- **Discovery**: cwd is included even when `.git` is a gitfile; independent clones in agent containers list as `orphan-dir` (trash the directory, prune only if `gitdir:` points at a main repo)

## Unchanged

- Delete funnel semantics (protection + Trash)
- Plan / apply JSON shapes and `schema_version`
- **No** `schema_version` bump
- `purge` / `clean` still do not delete worktree checkouts
