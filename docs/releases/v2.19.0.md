# v2.19.0

Home menu and list polish, plus a hidden `--plan` alias and a TouchID PAM fix.

## Added / changed since 2.18.0

- **Home**: numbered items, crate version on the brand, footer `H Helper`, refreshed screenshot
- **Lists**: wrap long records, show selected and total size, paginated `Q` labeled Quit
- **Worktree**: scan spinner while inventorying leftover checkouts
- **CLI**: `--dry-run` / `-n` are hidden aliases of `--plan` (help lists `--plan` only)
- **TouchID**: stage PAM edits in a user temp dir so the write does not fail on permissions

## Unchanged

- Delete funnel semantics (protection + Trash)
- Plan / apply JSON shapes and `schema_version`
- **No** `schema_version` bump
