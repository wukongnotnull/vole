# v2.2.0

产品 v2 续篇 **M7**：`vole installer` 高对齐主路径。

## 新增

- `vole installer`：扫描安装包（`.dmg` / `.pkg` / `.mpkg` / `.iso` / `.xip`，以及含 `.app`/`.pkg`/`.dmg`/`.xip` 载荷的 `.zip`）→ `--plan` → `--apply`
  - 扫描根对齐 Mole `INSTALLER_SCAN_PATHS`（Downloads / Desktop / Documents / Homebrew Caches 等）；默认深度 2
  - JSON / `--plan-out` / `--json-stream`；默认废纸篓，可 `--permanent`
  - 删除走既有安全漏斗（`mole_delete_verified` + identity TOCTOU）；禁止平行 `rm -rf`
  - 测试注入：`VOLE_INSTALLER_SCAN_ROOTS`、`VOLE_INSTALLER_SCAN_MAX_DEPTH`
  - 交互菜单与 shell 补全覆盖 `installer`
- apply 存在失败条目时非零退出（incomplete 精神）

## 承接

- 含 **2.1.0** `clean` hints
- 含 **2.0.0** `purge` 与命令别名
