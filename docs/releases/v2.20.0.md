# v2.20.0

New `vole agent` command lists leftover agent containers, sessions, and caches (not Git checkouts) and moves selected items to Trash after you confirm. Home adds item 7.

## Added / changed since 2.19.1

- **Command**: `vole agent` inventories leftover agent data on a closed allowlist (Cursor / Codex / Claude). TTY multi-select starts with nothing preselected, then Trash
- **Safety**: Git checkouts stay on `vole worktree`; agent never claims leftovers are safe to delete
- **Home**: seventh menu item Agent (digit 7); digits 1–6 unchanged; refreshed screenshot
- **Clean hints**: read-only LaunchAgent / orphan-dotdir long-tail (no `vole hints` command)
- **CLI**: `--help` and status footer list shipped commands / wired keys honestly
- **Install docs**: five-language README current-release examples; Home screenshot shows seven items
- **Fixtures**: Codex Desktop staging ages use `now-Nd` so CI clocks stay relative

## Unchanged

- Delete funnel semantics (protection + Trash)
- Plan / apply JSON shapes and `schema_version`
- **No** `schema_version` bump
- **No** Homebrew core formula
- `hints` stays a `clean` read-only probe, not a top-level command
