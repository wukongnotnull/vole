# v2.3.0

产品 v2 续篇 **M8**：`vole touchid` PAM Touch ID 引导开关。

## 新增

- `vole touchid`：对照 Mole `bin/touchid.sh`
  - 子命令：`status` / `enable` / `disable`；裸调用进入交互切换（Enter / Q）
  - 等价两阶段：`--plan` / `--dry-run` / `-n` 预览 → `enable` / `disable` 写入
  - 优先 `sudo_local` + `pam_tid.so`；legacy `/etc/pam.d/sudo` 使用 `.vole-backup` 备份与失败回滚
  - JSON 输出；交互菜单与 shell 补全覆盖 `touchid`
  - 测试注入：`VOLE_PAM_SUDO_FILE` / `VOLE_PAM_SUDO_LOCAL_FILE`
  - `VOLE_TEST_NO_AUTH=1` 下 Live 路径不写 PAM、不触发真 Touch ID / 交互 sudo

- 含 **2.0.0** `purge` 与命令别名
