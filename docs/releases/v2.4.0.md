# v2.4.0

产品 v2 续篇 **M9**：自更新通道 `vole update`。

## 新增

- `vole update`：对照 Mole `lib/manage/update.sh` + 安装校验精神
  - 稳定通道：GitHub Release 检测 → 下载 tarball + `SHA256SUMS` → sha256 校验 → 安装
  - 校验失败 **fail-closed**；禁止因校验失败静默降级到未校验源码安装
  - 成功以安装后 `vole --version` 为准
  - `--force` / `-f`：强制重装；Homebrew 安装时解除「优先 brew」拦截
  - `--nightly`：显式 nightly（brew 管理安装拒绝）
  - `--check`：只读检查；`--yes` / `-y`：非交互确认；`--json`
  - Homebrew 共存：默认提示 `brew upgrade vole`；自更新须确认 / `--force` / `--yes`
  - 裸调用 `vole` **不**联网检查更新（菜单仅可选手动 `update --check`）
- 发版资产新增 `SHA256SUMS`（`scripts/package-release.sh` / release workflow）
- 共享安装来源判定 `install_origin`（供后续 `remove` 复用）
