# v2.5.0

产品 v2 续篇 **M10**：自卸载 `vole remove`。

## 新增

- `vole remove`：对照 Mole `lib/manage/remove.sh`
  - `--dry-run` / `-n`：列全待删项（含 `brew uninstall vole` 提示），不删除
  - 默认交互确认；`--yes` / `-y` 非交互
  - `--purge-oplog`：显式才删除 Mole 兼容审计日志（默认保留）
  - `--json`：结构化探测 / dry-run / 结果
  - 三类安装形态：Homebrew、手动前缀、shell alias / 补全残留
  - Homebrew：调用 `brew uninstall vole`，**不**手撕 Cellar
  - 文件删除走 `validate_path_for_deletion` + `safe_remove` 漏斗
  - 复用 M9 `install_origin` 判定
- 交互菜单增加 `remove --dry-run` 只读预览入口
- `scripts/check-command-surface.sh`：`remove` 不再 MISSING；续篇命令面 required set 已覆盖
