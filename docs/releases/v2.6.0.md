# v2.6.0

`clean --plan` 广域目录体积对齐 Mole：对目录递归 `du`，修复 inode 体积导致合计严重偏低。

## 新增 / 修复

- **plan 目录体积**：目录 entry 改为有界并行递归 `du`（`measure_path_size_bytes`）；文件 / symlink 仍用 metadata
- **父子重叠扣减**：具名规则与广域 `Caches/*` / `Logs/*` 同树时，父目录展示体积扣减直接 plan 子孙，合计不双计
- **覆盖诚实**：`coverage_note` / 路线图标明 user.sh 广域 Caches/Logs 已落地；桌面特权 Helper 指向 vole-macos（D1）

## 验收参考

- 本机 `vole clean --plan --json`：修复前合计约 2.3GB → 修复后约数十 GB 量级（与本机 Caches 真实占用一致）
- `cargo test -p vole-core --lib ops::plan`
