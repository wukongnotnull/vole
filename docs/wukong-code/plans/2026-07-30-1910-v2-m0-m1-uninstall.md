# Vole M0/M1：`uninstall` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use wukong-code:subagent-driven-development (recommended) or wukong-code:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成产品 v2 里程碑 M0（Mole uninstall 主路径划界）与 M1（高对齐 `vole uninstall` plan→apply），发版 **1.1.0**。

**Architecture:** 镜像 `clean`：编排在 `vole-core::ops`，CLI 薄前端。扩展 `protection` 补齐 uninstall 语义（`should_protect_from_uninstall`、`MOLE_UNINSTALL_MODE`、官方卸载器、残留发现、sibling guard）。复用既有 `ProtoPlan` / `Report` / `StreamEvent`（`rule_id` 前缀 `uninstall:`），**不 bump** `schema_version`。独立 `apply_uninstall_proto_plan`（不依赖 clean 规则 TOML 的 guard 回查）。默认废纸篓；oplog `command = "uninstall"`。

**Tech Stack:** Rust 1.97.1、既有 `vole-core` / `vole-proto` / `vole-cli`、`plist`（Info.plist）、`data/protection.toml` + `scripts/gen-protection-toml.sh`、Mole 钉版 `third_party/mole-1.48.1`。

**Design:** [`docs/wukong-code/specs/2026-07-30-1900-v2-product-goals-design.md`](../specs/2026-07-30-1900-v2-product-goals-design.md)

## Global Constraints

- 许可证：GPL-3.0-only。
- 平台：仅 macOS；无 sudo / 真提权。
- 交互：`--plan` / `--apply` / `--permanent` / `--json` / `--json-stream` / `--plan-out`，对齐 `clean`。
- 深度：高对齐主路径；长尾 skip + `coverage_note` 提示继续用 Mole。
- 协议：仅追加可选字段（若必须）；禁止破坏既有 clean Plan 消费方。优先 **零 schema 变更**（靠 `rule_id` 约定）。
- 删除：一律经 `mole_delete_verified` + `validate_path_for_deletion`；uninstall 模式下 data-protected 可删，system-critical 不可。
- 残留匹配：仅 bundle id / app 名变体；拒绝通用词；短名地板；不做 TeamID 前缀通配（对齐 Mole AGENTS）。
- 任一 teardown 必须过 sibling guard。
- Mole 库存钉 `1.48.1`，不盲跟上游。
- 每个 Task 至少一次 commit；合并 main 前 CI 绿。
- 本计划 **不含** optimize（M2/M3）与 SwiftUI。

## 主路径 vs 长尾（M0 默认划界；Task 1 可微调但不得扩大长尾进 M1）

**M1 主路径（必须交付）**

1. 枚举 `/Applications` 与 `$HOME/Applications` 下 `*.app`
2. 读 `Contents/Info.plist` → `CFBundleIdentifier` / `CFBundleName` / `CFBundleDisplayName`
3. `should_protect_from_uninstall(bundle_id)` → 跳过系统关键（Apple 可卸 allowlist 除外）
4. `official_uninstaller_vendor(...)` 命中 → `SkipReason` + coverage 提示（不进删除条目）
5. `find_app_leftovers`：按 **精确** bundle id / 命名变体扫描用户域：
   - `~/Library/Containers/<bundle>`
   - `~/Library/Group Containers/*`（仅精确或已证明的变体；禁止 TeamID 通配扩张）
   - `~/Library/Preferences/<bundle>.plist`
   - `~/Library/Application Support/<name-variants>`
   - `~/Library/Caches/<bundle|name-variants>`
   - `~/Library/Logs/<...>`
   - `~/Library/Saved Application State/<bundle>.savedState`
   - `~/Library/LaunchAgents` 中 Program 指向该 app 的 plist（用户域）
6. Sibling guard：同 bundle id 的其他 `.app` 仍存在（含 `/Volumes`）→ 跳过共享残留 / 禁止危险 teardown
7. Plan 条目：`.app` 本体 + 通过校验的残留路径；`rule_id = "uninstall:<bundle_id>"` 或 `uninstall:leftover:<...>`
8. Apply：TTL + schema + TOCTOU + uninstall-mode 路径保护 + `mole_delete_verified`；默认 Trash

**M1 长尾（coverage_note 诚实跳过，不实现）**

- Homebrew cask `zap` / `brew uninstall --cask`
- Login items（AppleScript / SMAppService 交互）
- 系统级 LaunchDaemons / PrivilegedHelperTools（需 sudo）
- `/Library` 下广域残留
- 交互式 TTY 多选 UI（Mole 菜单）；Vole 用 plan JSON / `--json` 代替
- `purge` / orphaned apps

    let catalog = ProtectionCatalog::embedded();

    let bundle = "com.freemacsoft.AppCleaner"; // data/protection.toml data_protected_bundles
    assert!(catalog.matches_data_protected(bundle));
        // Application Support（非 explicit cache）在 cleanup 下受 data_protected 保护。
        let path = format!("/Users/test/Library/Application Support/{bundle}");

}
