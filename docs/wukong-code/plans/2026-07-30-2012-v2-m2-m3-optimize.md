# Vole M2/M3：`optimize` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use wukong-code:subagent-driven-development (recommended) or wukong-code:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成产品 v2 里程碑 M2（Mole optimize 任务子集划界）与 M3（高对齐 `vole optimize` plan→apply），发版 **1.2.0**。

**Architecture:** 镜像 `clean` / `uninstall`：编排在 `vole-core::ops`，CLI 薄前端。Rust 侧维护与 Mole `catalog.sh` 对齐的 **任务目录**；plan 阶段把可预览工作写成 `ProtoPlan` 条目（`rule_id` 前缀约定动作种类），apply 阶段按前缀分发到删除或副作用 handler。**不 bump** `schema_version`。无 sudo；需提权任务一律 skip + `coverage_note`。默认废纸篓仅用于删除类条目；oplog `command = "optimize"`。

**Tech Stack:** Rust 1.97.1、`vole-core` / `vole-proto` / `vole-cli`、`plutil`/`sqlite3` 经 `std::process::Command`（与 Mole 同依赖面）、Mole 钉版 `third_party/mole-1.48.1`。

**Design:** [`docs/wukong-code/specs/2026-07-30-1900-v2-product-goals-design.md`](../specs/2026-07-30-1900-v2-product-goals-design.md)

## Global Constraints

- 许可证：GPL-3.0-only。
- 平台：仅 macOS；**无 sudo / 真提权**（与窄 v2 §4.2 一致）。
- 交互：`--plan` / `--apply` / `--permanent` / `--json` / `--json-stream` / `--plan-out`，对齐 `clean`。
- 深度：高对齐主路径；长尾 skip + `coverage_note` 提示继续用 Mole。
- 协议：优先 **零 schema 变更**；用 `rule_id` 约定动作：
  - `optimize:delete:<task_id>` — 走 `mole_delete_verified`（默认 Trash）
  - `optimize:action:<task_id>` — 走具名副作用 handler（VACUUM / defaults / killall 等）；`path` 为主要目标文件或 sentinel 目录
- 删除：一律经 `validate_path_for_deletion` + `ProtectionMode::Cleanup`（optimize **不**用 Uninstall 模式放宽 data-protected）。
- Mole 库存钉 `1.48.1`，不盲跟上游。
- 每个 Task 至少一次 commit；合并 main 前 CI 绿。
- 本计划 **不含** SwiftUI、`purge`、真 sudo。

## 主路径 vs 长尾（M2 默认划界；Task 1 可微调但不得把 sudo 任务扩进 M3）

Mole catalog 共 **23** 个 action（`lib/optimize/catalog.sh`）。

### M3 主路径（必须交付）

| Mole action | 形态 | Vole 策略 |
|---|---|---|
| `cache_refresh` | delete | 用户域 QuickLook / iconservices 缓存目录 |
| `saved_state_cleanup` | delete | `~/Library/Saved Application State/*.savedState`，mtime > 30 天 |
| `fix_broken_configs` | delete | `plutil -lint` 失败且非 Apple 的 `~/Library/Preferences/*.plist` |
| `quarantine_cleanup` | action | `QuarantineEventsV2` DELETE+VACUUM |
| `sqlite_vacuum` | action | Mail/Safari/Messages DB；app 运行中则 skip 该库 |
| `prevent_network_dsstore` | action | `defaults write com.apple.desktopservices DSDontWriteNetworkStores -bool true`（及 USB 同款若 Mole 有） |
| `legacy_overrides_audit` | delete/action | 对照 Mole 移除遗留 App Nap / 镜像校验 override |
| `launch_agents_cleanup` | delete | 用户域 LaunchAgents 中 Program 不存在的 plist |
| `notification_cleanup` | delete/action | 对照 Mole 清理旧通知数据（用户域） |
| `coreduet_cleanup` | delete | 对照 Mole 用户域 usage 数据 |
| `dock_refresh` | action | `killall Dock`（仅 apply；plan 用 sentinel 条目） |
| `launch_services_rebuild` | action | 用户态 `lsregister -kill -r -domain local -domain system -domain user` 对照 Mole |

### M3 长尾（coverage_note 诚实跳过，不实现）

| Mole action | 原因 |
|---|---|
| `system_maintenance` | DNS flush 需 sudo |
| `network_optimization` | 同上 |
| `memory_pressure_relief` | `sudo purge` |
| `network_stack_optimize` | `sudo route` / `arp` |
| `disk_permissions_repair` | `sudo diskutil resetUserPermissions` |
| `spotlight_index_optimize` | 重建索引常需 sudo |
| `spotlight_orphan_rules_cleanup` | 系统 Spotlight 规则面；易误伤 |
| `periodic_maintenance` | `sudo periodic` |
| `disk_verify` | 诊断向；修复需 sudo |
| `login_items_audit` | AppleScript / `sfltool` sudo；仅报告难 plan |
| `shared_file_list_repair` | 与 login items 同级复杂度；M3 先跳过 |

**交互长尾：** Mole TTY 动画 / health JSON 大屏；Vole 用 plan JSON + 可选简短人读摘要。不移植 `bc` 依赖的 health 仪表（可用既有 `vole status`）。
