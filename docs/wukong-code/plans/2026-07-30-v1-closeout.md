# Vole v1 Closeout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use wukong-code:executing-plans (preferred) or subagent-driven-development. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 宣告设计文档中的 v1 CLI 产品目标完成；发 **v0.0.11**（509 规则）；把可选长尾（Toolbox / Codex staging / plan 去重）排入 v1.x，不阻塞发版。

**Tech Stack:** 既有 Rust workspace、GitHub Release、Homebrew Formula、`scripts/package-release.sh` / `update-homebrew-formula.sh`。

**Design / 依据:** `docs/wukong-code/specs/2026-07-29-rust-rewrite-design.md` §1；`docs/wukong-code/specs/2026-07-30-v1-closeout-design.md`；用户批准方案 2026-07-30。

## Global Constraints

- 许可证：GPL-3.0-only。
- 平台：仅 macOS；不引入 sudo / uninstall / purge 等 v1 非目标。
- 不跟踪 Mole 上游演进；库存钉 v1.48.1。
- 发版 tag 形如 `v0.0.11`；Release body 用 `docs/releases/v0.0.11.md`。
