### Task 3: plan sentinel + apply 门控 + 接线

**Files:**
- Modify: `crates/vole-core/src/optimize/tasks/actions.rs`
- Modify: `crates/vole-core/src/optimize/tasks/mod.rs`、`optimize/mod.rs`

- Modify: `crates/vole-core/src/ops/optimize_apply.rs`
- Test: actions / optimize_plan / optimize_apply

**Interfaces:**
- Produces plan:

```rust
pub fn plan_network_stack_optimize(home: &Path) -> OptimizeCandidate;
pub fn plan_disk_permissions_repair(home: &Path) -> OptimizeCandidate;
pub fn plan_periodic_maintenance(home: &Path) -> OptimizeCandidate;
```

- Produces gates（可 `pub(crate)` 或 `pub` 供 apply/`needs_optimize_privilege`）：

```rust
pub fn has_active_vpn() -> bool;           // VOLE_TEST_VPN_ACTIVE=1|0
pub fn network_stack_needs_flush() -> bool; // VOLE_TEST_NETWORK_STACK_UNHEALTHY=1|0；否则 route default + dscacheutil example.com
pub fn needs_disk_permissions_repair(home: &Path) -> bool; // VOLE_TEST_DISK_PERMISSIONS_NEED_REPAIR；否则 owner/writable
pub fn periodic_needs_run() -> bool;       // VOLE_TEST_PERIODIC_*；命令存在 + daily.out 缺失或年龄≥7d
```

- `apply_optimize_action` 增加三分支：
  - network：VPN → `Ok`；`!needs_flush` → `Ok`；否则 `flush_network_stack`
  - disk：`!needs_repair` → `Ok`；否则 `reset_user_permissions(uid)`
  - periodic：`!needs_run` → `Ok`；否则 `run_periodic_maintenance`
- `needs_optimize_privilege`：

```rust
"network_stack_optimize" => !has_active_vpn() && network_stack_needs_flush(),
"disk_permissions_repair" => needs_disk_permissions_repair(/* home from env? */),
"periodic_maintenance" => periodic_needs_run(),
```

  **注意**：`needs_disk_permissions_repair` 需 home。`optimize_apply` 已有 `ctx.options.home`：扩展 `needs_optimize_privilege(task_id, home: &Path)`。

- plan：`allow(...)` 时 push 三 sentinel
- 单测：coverage note **不含** "Network Stack Refresh" / "Permission Repair" / "Periodic Maintenance"；仍含 Spotlight / Shared File Lists 等
