# Vole M6：`clean` hints → 2.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use wukong-code:executing-plans（本仓默认 inline）或 wukong-code:subagent-driven-development。Steps 用 checkbox（`- [ ]`）跟踪。

**Goal:** 在 `vole clean` plan 路径交付只读 hints 主路径子集（项目构建物快捷探针 + System Data 线索），超时降级不阻塞 clean，发版 **2.1.0**；禁止顶层 `vole hints`。

**Architecture:** `vole-core::ops::clean_hints` 产出 `CleanHints`；CLI 在 plan 人读/JSON 渲染。复用 purge 的 `purge_paths` / `PURGE_TARGETS`（减去 quick-hint 排除项）。ProtoPlan 追加可选 `hints` 字段，不 bump `schema_version`。

**Tech Stack:** Rust workspace、`std::fs` 浅列目录、超时 `du`（`duct`/`std::process` + 时限，对齐现有超时习惯）、`vole-proto` serde 可选字段。

**Design:** [`../specs/2026-08-08-2143-v2-m6-clean-hints-design.md`](../specs/2026-08-08-2143-v2-m6-clean-hints-design.md)

## Global Constraints

- 权威续篇规格：`docs/wukong-code/specs/2026-08-08-2030-v2-cli-complete-design.md`
- Mole 钉版：`third_party/mole-1.48.1`；quick-hint 排除 `bin`/`vendor` 钉死
- **只读**：禁止删除漏斗；超时/错误 → 跳过提示
- **禁止** `Command::Hints` / `vole hints` 顶层子命令
- 包版本在功能就绪后升 **2.1.0**（不得空 bump）
- TDD：先红测再实现；每 Task commit
- 合入用 merge commit（非 squash）；本阶段开 PR 不自动 merge

```rust
#[test]
fn project_artifact_hint_counts_node_modules_excludes_vendor_bin() {
    let home = tempfile::tempdir().unwrap();
    let root = home.path().join("hints-root");
    fs::create_dir_all(root.join("proj/node_modules")).unwrap();
    fs::create_dir_all(root.join("proj/vendor")).unwrap();
    fs::create_dir_all(root.join("proj/bin")).unwrap();
    fs::write(root.join("proj/package.json"), "{}").unwrap();
    let cfg = home.path().join(".config/vole");
    fs::create_dir_all(&cfg).unwrap();
    fs::write(cfg.join("purge_paths"), format!("{}\n", root.display())).unwrap();

    let hints = collect_clean_hints(&CleanHintsOptions {
        home: home.path(),
        search_roots: None,
        budget: Duration::from_secs(15),
        list_timeout: Duration::from_secs(1),
        du_timeout: Duration::from_millis(800),
        now: Instant::now(),
    });
    let item = hints.items.iter().find(|h| h.kind == HintKind::ProjectArtifacts).unwrap();
    assert!(item.summary.contains("1") || item.summary.contains("dirs"));
    assert!(!item.summary.to_lowercase().contains("vendor"));
}
```
