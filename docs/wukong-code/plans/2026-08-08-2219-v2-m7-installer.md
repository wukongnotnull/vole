**Tech Stack:** Rust workspace、`jwalk`（已有）、`std::process` 调 `zipinfo`/`unzip`、`vole-proto` schema 不变。

- [ ] **Step 1: 写失败单测**

在 `installer_plan.rs` 的 `#[cfg(test)]`：

```rust
#[test]
fn plan_finds_dmg_and_pkg_skips_symlink() {
    let root = tempfile::tempdir().unwrap();
    let downloads = root.path().join("Downloads");
    fs::create_dir_all(&downloads).unwrap();
    fs::write(downloads.join("App.dmg"), b"x").unwrap();
    fs::write(downloads.join("Setup.pkg"), b"y").unwrap();
    // symlink should be skipped
    std::os::unix::fs::symlink(downloads.join("App.dmg"), downloads.join("link.dmg")).unwrap();
    fs::write(downloads.join("notes.txt"), b"z").unwrap();

    let protection = AppProtection::new();
    let opts = InstallerPlanOptions {
        home: root.path(),
        ttl_secs: 900,
        scan_roots: Some(&[downloads.clone()]),
        max_depth: 2,
        now: SystemTime::now(),
    };
    let plan = build_installer_plan(&protection, &opts).unwrap();
    let paths: Vec<_> = plan.entries.iter().map(|e| e.path.clone()).collect();
    assert_eq!(paths.len(), 2);
    assert!(paths.iter().any(|p| p.ends_with("App.dmg")));
    assert!(paths.iter().any(|p| p.ends_with("Setup.pkg")));
    assert!(plan.entries.iter().all(|e| e.rule_id.starts_with("installer:")));
}
```

另测：zip 含 `.app/` 条目才入选（若系统无 zipinfo/unzip，跳过或用 `#[ignore]` 条件）；普通 zip 不含安装载荷则不进 plan。
