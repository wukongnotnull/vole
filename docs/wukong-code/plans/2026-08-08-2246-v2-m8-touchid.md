# Vole M8：`touchid` → 2.3.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use wukong-code:executing-plans（本仓默认 inline）或 wukong-code:subagent-driven-development。Steps 用 checkbox（`- [ ]`）跟踪。

**Goal:** 实现高对齐 `vole touchid`（PAM Touch ID 引导开关：status / plan·dry-run → enable·disable；菜单 / 补全 / JSON），发版 **2.3.0**。

**Architecture:** `vole-core::ops::touchid` 纯逻辑读写注入的 PAM 路径；`PamInstall` trait 抽象特权安装（Fake 写文件；Live 仅 `sudo -n`）。CLI 薄前端。等价两阶段 = `--plan`/`--dry-run` 预览 → `enable`/`disable` 写入。**不**走删除 ProtoPlan。

**Tech Stack:** Rust workspace；`std::fs` + 可选 `std::process::Command`（仅 Live `sudo -n`）；serde_json 输出。

**Design:** [`../specs/2026-08-08-2245-v2-m8-touchid-design.md`](../specs/2026-08-08-2245-v2-m8-touchid-design.md)

## Global Constraints

- 权威续篇规格：`docs/wukong-code/specs/2026-08-08-2030-v2-cli-complete-design.md` §5 M8 / §6.4

### Task 1: touchid 核心 — status / plan / sudo_local enable·disable（Fake）

**Files:**
- Create: `crates/vole-core/src/ops/touchid.rs`
- Modify: `crates/vole-core/src/ops/mod.rs`

**Interfaces:**
- Consumes: `crate::delete::config::test_no_auth`
- Produces:
  - `pub const PAM_TID_LINE: &str = "auth       sufficient     pam_tid.so";`
  - `pub trait PamInstall { fn install_file(&self, src: &Path, dst: &Path) -> io::Result<()>; fn copy_file(&self, src: &Path, dst: &Path) -> io::Result<()>; }`
  - `pub struct FakePamInstall;` — `fs::copy` / write via rename
  - `pub struct TouchIdPaths { pub sudo: PathBuf, pub sudo_local: PathBuf }`
  - `pub fn resolve_touchid_paths() -> TouchIdPaths` — 读 `VOLE_PAM_SUDO_FILE` / `VOLE_PAM_SUDO_LOCAL_FILE`，否则默认 `/etc/pam.d/sudo` 与旁路 `sudo_local`
  - `pub fn is_touchid_configured(paths: &TouchIdPaths) -> bool`
  - `pub enum TouchIdAction { Enable, Disable, None }`
  - `pub struct TouchIdPlan { pub configured: bool, pub uses_sudo_local: bool, pub action: TouchIdAction, pub targets: Vec<PathBuf>, pub note: Option<String> }`
  - `pub fn plan_touchid(paths: &TouchIdPaths, intent: Option<TouchIdAction>) -> TouchIdPlan` — `intent=None` 时预览切换方向
  - `pub enum TouchIdOutcome { AlreadyEnabled, AlreadyDisabled, Enabled, Disabled, DryRun, SkippedNoAuth, Failed(String) }`
  - `pub fn enable_touchid(paths: &TouchIdPaths, installer: &dyn PamInstall, dry_run: bool) -> Result<TouchIdOutcome, TouchIdError>`
  - `pub fn disable_touchid(...)` 同上
  - Live 路径下若 `test_no_auth()` 且非 Fake：enable/disable 返回 `SkippedNoAuth` 且**零** `install_file` 调用（见 Task 2 Live 测；本 Task 用 Fake 全绿）

fn status_reads_sudo_local_first() {

fn enable_writes_sudo_local_when_sudo_mentions_it() {
    let dir = tempfile::tempdir().unwrap();
    let sudo = dir.path().join("sudo");
    let local = dir.path().join("sudo_local");
    fs::write(&sudo, "#\n# sudo: via sudo_local\n").unwrap();

        sudo: sudo.clone(),
        sudo_local: local.clone(),
    };
    let out = enable_touchid(&paths, &FakePamInstall, false).unwrap();
    assert!(matches!(out, TouchIdOutcome::Enabled));
    let body = fs::read_to_string(&local).unwrap();

#[test]
fn disable_removes_tid_from_sudo_local() {
    let dir = tempfile::tempdir().unwrap();
    let sudo = dir.path().join("sudo");
    let local = dir.path().join("sudo_local");
    fs::write(&sudo, "sudo_local\n").unwrap();
    fs::write(&local, format!("# hdr\n{PAM_TID_LINE}\n")).unwrap();
    let paths = TouchIdPaths { sudo, sudo_local: local.clone() };
    let out = disable_touchid(&paths, &FakePamInstall, false).unwrap();
    assert!(matches!(out, TouchIdOutcome::Disabled));
    assert!(!fs::read_to_string(&local).unwrap().contains("pam_tid.so"));
}

#[test]
fn dry_run_enable_does_not_create_sudo_local() {
    let dir = tempfile::tempdir().unwrap();

    let local = dir.path().join("sudo_local");
    fs::write(&sudo, "sudo_local\n").unwrap();
    let paths = TouchIdPaths { sudo, sudo_local: local.clone() };
    let out = enable_touchid(&paths, &FakePamInstall, true).unwrap();
    assert!(matches!(out, TouchIdOutcome::DryRun));
    assert!(!local.exists());
}

### Task 2: legacy sudo 路径 + 备份回滚 + VOLE_TEST_NO_AUTH Live 闸

**Files:**
- Modify: `crates/vole-core/src/ops/touchid.rs`

**Interfaces:**
- Produces: legacy enable（注释后插入 tid）、`<sudo>.vole-backup`、install 失败回滚；`LivePamInstall`（`sudo -n install …` / `sudo -n cp`）；`pub fn pam_install_for_runtime() -> Box<dyn PamInstall>` — 若 `test_no_auth()` 返回 `NoAuthPamInstall`（所有写操作返回错误或被上层短路）
- `enable_touchid` / `disable_touchid`：**在调用任何 installer 之前**若 `test_no_auth()` → `Ok(SkippedNoAuth)`（即使传入 Fake 以外的 Live；单测用 env）

- [ ] **Step 1: 写失败单测**

```rust
#[test]
fn legacy_enable_creates_backup_and_inserts_tid() {
    let dir = tempfile::tempdir().unwrap();
    let sudo = dir.path().join("sudo");
    let local = dir.path().join("sudo_local");
    fs::write(&sudo, "# comment\nauth required pam_opendirectory.so\n").unwrap();
    let paths = TouchIdPaths { sudo: sudo.clone(), sudo_local: local };
    enable_touchid(&paths, &FakePamInstall, false).unwrap();
    assert!(sudo.with_extension("vole-backup").exists()
        || PathBuf::from(format!("{}.vole-backup", sudo.display())).exists());
    let body = fs::read_to_string(&sudo).unwrap();
    assert!(body.contains("pam_tid.so"));
    // tid 出现在首个非注释行之前或作为首个 auth 行
    let non_comment = body.lines().find(|l| !l.starts_with('#')).unwrap();
    assert!(non_comment.contains("pam_tid.so"));
}

#[test]
fn enable_skips_when_vole_test_no_auth() {
    std::env::set_var("VOLE_TEST_NO_AUTH", "1");
    let dir = tempfile::tempdir().unwrap();
    let sudo = dir.path().join("sudo");
    let local = dir.path().join("sudo_local");
    fs::write(&sudo, "sudo_local\n").unwrap();
    let paths = TouchIdPaths { sudo, sudo_local: local.clone() };
    let out = enable_touchid(&paths, &FakePamInstall, false).unwrap();
    // 设计：VOLE_TEST_NO_AUTH 对所有 writer 短路，保证 CLI Live 永不挂起
    assert!(matches!(out, TouchIdOutcome::SkippedNoAuth));
    assert!(!local.exists());
    std::env::remove_var("VOLE_TEST_NO_AUTH");
}
```

备份路径钉死：`PathBuf::from(format!("{}.vole-backup", sudo.display()))`（不用 `with_extension`，避免替换 `.d` 等）。

迁移测：sudo 含 `sudo_local` + legacy tid → enable 后 sudo 无 tid、local 有 tid。

回滚测：用 `FailingPamInstall`（第一次 `install_file` 失败）在 legacy 路径上；断言 sudo 内容恢复为备份或保持未改。

fn touchid_help_and_status_json_with_injected_pam() {
    let dir = tempfile::tempdir().unwrap();

    let local = dir.path().join("sudo_local");
    fs::write(&sudo, "sudo_local\n").unwrap();
    let output = Command::new(env!("CARGO_BIN_EXE_vole"))
