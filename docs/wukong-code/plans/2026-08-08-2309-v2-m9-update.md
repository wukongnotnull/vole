# Vole M9：`update` → 2.4.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use wukong-code:executing-plans（本仓默认 inline）或 wukong-code:subagent-driven-development。Steps 用 checkbox（`- [ ]`）跟踪。

**Goal:** 实现自更新通道 `vole update`（检测 → 下载 → 校验 → 安装；`--force` / `--nightly` / `--check`；brew 共存；fail-closed），发版 **2.4.0**。

**Architecture:** `install_origin` 判定 Homebrew vs Manual；`update` 编排经可注入 `UpdateTransport` 下载 Release 资产与 `SHA256SUMS`，sha256 fail-closed 后安装到当前 prefix；成功看安装后 `--version`。CLI 薄前端。裸调用菜单不联网。

**Tech Stack:** Rust workspace；`sha2`（或 `sha256` via `ring`/`sha2`）校验；`flate2`+`tar` 解压；生产下载走 `curl`（Command）；测试 Fake transport；无真网单测。

**Design:** [`../specs/2026-08-08-2308-v2-m9-update-design.md`](../specs/2026-08-08-2308-v2-m9-update-design.md)

## Global Constraints

- 权威续篇规格：`docs/wukong-code/specs/2026-08-08-2030-v2-cli-complete-design.md` §5 M9 / §6.5

### Task 2: update 核心 — checksum fail-closed + 安装成功判据

**Files:**
- Create: `crates/vole-core/src/ops/update.rs`
- Modify: `crates/vole-core/src/ops/mod.rs`
- Modify: `crates/vole-core/Cargo.toml`（`sha2`, `hex`, `tar`, `flate2`）

**Interfaces:**
- Consumes: `InstallLayout`, `InstallOrigin`
- Produces:
  - `pub struct UpdateOptions { pub force: bool, pub nightly: bool, pub check_only: bool, pub yes: bool, pub current_version: String, pub binary_path: PathBuf, pub config_dir: PathBuf, pub confirm_brew_self_update: bool }`
  - `pub trait UpdateTransport { fn latest_stable_tag(&self) -> Result<String, UpdateError>; fn latest_main_commit(&self) -> Result<String, UpdateError>; fn download(&self, url: &str, dest: &Path) -> Result<(), UpdateError>; }`
  - `pub struct FakeUpdateTransport { ... }` — 内存映射 URL→bytes；可设 latest tag / commit
  - `pub enum UpdateOutcome { AlreadyLatest { version: String }, Check { current: String, latest: Option<String>, origin: InstallOrigin, channel: String }, Updated { version: String }, BrewPreferred, NightlyBrewRejected, Failed(String), DryBlocked }`
  - `pub fn run_update(opts: &UpdateOptions, transport: &dyn UpdateTransport) -> Result<UpdateOutcome, UpdateError>`
  - 稳定资产 URL：`https://github.com/{repo}/releases/download/v{ver}/vole-{ver}-{arch}.tar.gz` 与同目录 `SHA256SUMS`
  - `verify_sha256(path, sums_text, asset_name) -> Result<(), UpdateError>`
  - 安装：解压 tarball，将 `*/bin/vole` 原子替换到 `prefix_bin/vole`；可选同步 `share/vole/rules`
  - 成功：对**新**二进制执行 `--version`（通过注入 `VersionProbe` 或写 stub 脚本）；token == target
  - brew + !force + !yes + !confirm → `BrewPreferred`（不 download）
  - brew + nightly → `NightlyBrewRejected`
  - checksum 失败 → `Err` / `Failed`，绝不调用源码安装

- [ ] **Step 1: 写失败单测**

```rust
#[test]
fn checksum_mismatch_is_fail_closed() {
    let dir = tempfile::tempdir().unwrap();
    let bin = dir.path().join("bin");
    fs::create_dir_all(&bin).unwrap();
    let exe = bin.join("vole");
    fs::write(&exe, b"old").unwrap();
    let sums = "deadbeef  vole-9.9.9-aarch64-apple-darwin.tar.gz\n";
    // Fake transport serves tarball bytes whose sha256 != deadbeef
    let transport = FakeUpdateTransport::stable("9.9.9", b"not-a-real-tar", sums);
    let opts = UpdateOptions {
        force: true,
        nightly: false,
        check_only: false,
        yes: true,
        current_version: "2.3.0".into(),
        binary_path: exe,
        config_dir: dir.path().to_path_buf(),
        confirm_brew_self_update: false,
    };
    let err = run_update(&opts, &transport).unwrap_err();
    assert!(format!("{err}").to_ascii_lowercase().contains("checksum"));
}

#[test]

}
```
