# Vole M10：`remove` → 2.5.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use wukong-code:executing-plans（本仓默认 inline）或 wukong-code:subagent-driven-development。Steps 用 checkbox（`- [ ]`）跟踪。

**Goal:** 实现自卸载 `vole remove`（三类安装形态、`--dry-run`、默认确认、brew 不撕 Cellar、删除走漏斗），发版 **2.5.0**。

**Architecture:** 复用 M9 `install_origin`；`ops::remove` 探测并生成 `RemovePlan`，dry-run 只打印；apply 时 brew 走可注入 `BrewUninstaller`，其余路径经 `validate_path_for_deletion` + `safe_remove`（`NoPathProtection`，因清单已是自有产物白名单；系统 critical 仍由校验硬拦）。CLI 薄前端；菜单只挂 `remove --dry-run`。

**Tech Stack:** Rust workspace；既有 `safe_remove` / `FsRemover` / `OperationLogger`；生产 brew 经 `std::process::Command`；测试 FakeBrew + tempfile `$HOME`。

**Design:** [`../specs/2026-08-08-2332-v2-m10-remove-design.md`](../specs/2026-08-08-2332-v2-m10-remove-design.md)

### Task 1: `ops::remove` 探测 + dry-run plan

**Files:**
- Create: `crates/vole-core/src/ops/remove.rs`
- Modify: `crates/vole-core/src/ops/mod.rs`

**Interfaces:**
- Consumes: `detect_install_layout`, `InstallOrigin`, `default_config_dir`
- Produces:
  - `pub enum RemoveItemKind { BrewUninstall, ManualBinary, ShareTree, AliasOrCompletion, Config, Cache, ToolLogs, Oplog }`
  - `pub struct RemoveItem { pub kind: RemoveItemKind, pub path: Option<PathBuf>, pub note: Option<String> }`
  - `pub struct RemovePlan { pub items: Vec<RemoveItem>, pub homebrew: bool }`
  - `pub struct RemoveOptions { pub dry_run: bool, pub yes: bool, pub purge_oplog: bool, pub binary_path: PathBuf, pub home: PathBuf, pub config_dir: PathBuf }`
  - `pub fn plan_remove(opts: &RemoveOptions) -> RemovePlan`
  - Homebrew：`origin==Homebrew` → `homebrew=true` + item `BrewUninstall`（`note="brew uninstall vole"`）；**不**把 `*/Cellar/vole/*` 或 brew bin symlink 放进可删 paths
  - 手动：当前 Manual exe；另扫 `{home}/.local/bin/vole`、`/usr/local/bin/vole`、`/opt/local/bin/vole`（存在且非 Cellar symlink）
  - share：手动二进制的 `prefix/../share/vole` 或 `prefix_bin` 的父级 `share/vole` 若存在
  - 补全残留：`{home}/.config/fish/completions/vole.fish`；`{home}/.local/share/bash-completion/completions/vole`；`{home}/.zfunc/_vole`（存在才入清单）
  - 默认：`config_dir`、`{home}/.cache/vole`、`{home}/Library/Logs/vole`（存在才入）
  - `--purge-oplog`：额外 `{home}/Library/Logs/mole/operations.log`、`deletions.log`
  - 空清单 → `items.is_empty() && !homebrew`

#[test]
fn dry_run_lists_brew_not_cellar_path() {
    let dir = tempfile::tempdir().unwrap();
    let cellar = dir.path().join("Cellar/vole/2.4.0/bin");
    fs::create_dir_all(&cellar).unwrap();
    let real = cellar.join("vole");
    fs::write(&real, b"x").unwrap();
    let bin = dir.path().join("bin");
    fs::create_dir_all(&bin).unwrap();
    let link = bin.join("vole");
    std::os::unix::fs::symlink(&real, &link).unwrap();
    let home = dir.path().join("home");
    fs::create_dir_all(home.join(".config/vole")).unwrap();
    let opts = RemoveOptions {
        dry_run: true,
        yes: true,
        purge_oplog: false,
        binary_path: link,
        home: home.clone(),
        config_dir: home.join(".config/vole"),
    };
    let plan = plan_remove(&opts);
    assert!(plan.homebrew);
    assert!(plan.items.iter().any(|i| i.kind == RemoveItemKind::BrewUninstall));
    assert!(!plan.items.iter().any(|i| {
        i.path.as_ref().is_some_and(|p| p.to_string_lossy().contains("Cellar/vole"))
    }));
    assert!(plan.items.iter().any(|i| i.kind == RemoveItemKind::Config));
}

### Task 2: apply — brew trait + safe_remove 漏斗

**Files:**
- Modify: `crates/vole-core/src/ops/remove.rs`

**Interfaces:**
- Produces:
  - `pub trait BrewUninstaller { fn uninstall_vole(&self) -> Result<(), String>; }`
  - `pub struct FakeBrewUninstaller { pub calls: std::sync::Mutex<u32>, pub fail: bool }`
  - `pub struct LiveBrewUninstaller;` — `brew uninstall vole`（查找 PATH / `/opt/homebrew/bin/brew` / `/usr/local/bin/brew`）
  - `pub enum RemoveOutcome { DryRun(RemovePlan), NothingFound, Removed { plan: RemovePlan, errors: Vec<String> }, NeedsConfirmation }`
  - `pub fn run_remove(opts: &RemoveOptions, brew: &dyn BrewUninstaller) -> Result<RemoveOutcome, RemoveError>`
  - `dry_run` → `DryRun(plan)` 不调 brew、不删
  - `!yes` → `NeedsConfirmation`（CLI 负责 prompt 后以 `yes=true` 再调）
  - apply：先 brew（若 `homebrew`）；再对每个有 `path` 的 item：拒绝含 `Cellar/vole`；`validate_path_for_deletion(path, &NoPathProtection)`；`safe_remove(..., FsRemover, silent=false, dry_run=false)`；失败收集到 `errors`，继续
  - `VOLE_NO_OPLOG=1` 可在测里关掉 logger 副作用；或 logger 写到 temp home（默认 mole 路径相对 `$HOME`）

fn apply_deletes_manual_via_funnel_not_raw_rm() {

}
