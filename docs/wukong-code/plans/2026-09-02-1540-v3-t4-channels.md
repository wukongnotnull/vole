# V3 Track 4：现有渠道（README / 安装 / Formula / 截图）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use wukong-code:subagent-driven-development (recommended) or wukong-code:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让五语 README、安装 AI prompt、tap Formula 说明和 TUI 截图与**当时已合入 main 的命令面**对齐；Home 第 7 项落地后再更新 `images/tui/home.png`。不把未合入的 `agent` 写成已发布。

**Architecture:** 本轨只动文档与 `Formula/vole.rb` 注释/说明。不进 `vole-core`。命令是否「已发布」以 `crates/vole-cli/src/main.rs` 是否存在 `Command::Agent` **且**该提交已在文档所跟踪的分支上为准。Formula 的 version/sha 仍走发版确认，本轨不打 tag、不建 Release、不提交 Homebrew core。

**Tech Stack:** 五语 Markdown、仓库内 tap `Formula/vole.rb`、`scripts/update-homebrew-formula.sh`（仅在用户明确确认发版后）、`images/tui/home.png`。

## Global Constraints

以下逐条抄自已批准规格 `docs/wukong-code/specs/2026-09-02-1530-v3-cli-generation-design.md`（§1–§4.4 / §5 / §7）。每一 Task 都隐含遵守本节。

- `schema_version`：默认不 bump；本规格不授权 bump。轨 3 若发现协议缺字段，另开补丁 design

- hints：无命中且未 skip → 不打印；仅当该探针 `scan_skipped` 时打一行 skip；`--apply` 仍不跑 hints

- 不改公证 / 签名流水线语义
